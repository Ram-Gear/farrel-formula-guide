Farrel Formula Guide Explanation of the Farrel formula, manual #610A pp. 45 & 46

Help

The formula

CTTT @ PDE = PDE · ((π/2 + 2·TANPAT·DPT·X) / N + INVPAT − INVPATE)

This formula will calculate the CTTT @ PDE but only if the PDE, OD, DPT, PAT, number of teeth & comparator reading are known.

Ask Grok: explain this formula

Applying it to a gearset

This may be applied to a gearset if all gearset specs are known:

CPT @ PDE = CTTTP @ PDPE + CTTTG @ PDGE  (at the condition of BL = 0.000)

CPT @ PDE = CTTTP @ PDPE + CTTTG @ PDGE + BLCT

CPN @ PDE = CTTNP @ PDPE + CTTNG @ PDGE + BLCN

Note: BLCN is assumed to be “feeler gage backlash”.

The formula may be re-configured for a gearset to calculate CRP, CRG, chordal & span dimensions with set backlash input.

Program “BL TO CR'S B&S SPAN”

Makes these conversions.

This program will handle “odd OD’s” & “extended centers”.

Ask Grok: pitch = thicknesses + backlash

Applying it to an individual gear (or pinion)

The formula may also be applied to an individual gear (or pinion). In this case, the PDE = PD, INVPAT = INVPATE, C = CE & RC = 1.000.

This is very helpful when “odd OD’s” &/or “odd CR’s” are encountered.

Note: Not all gearsets have the “set backlash” divided equally between the gear & pinion.

Program “CRG OR CRP TO B&S SPAN”

Converts these comparator readings to circular tooth thickness, span dimensions & chordal dimensions.

Oilfield herringbone drawings

Drawings for oilfield herringbone gears & pinions usually list only CRP, ODP, CRG, ODG, PAT, HA & CE. They are usually operated on “standard centers”.

Program “CR'S TO TO BL SPAN B&S”

Converts these comparator readings to circular tooth thicknesses, span dimensions, chordal dimensions & set backlash.

This program will handle “odd OD’s” & “extended centers”.

Industrial herringbone drawings

Sometimes a drawing for an “industrial” herringbone gear (or pinion) will list “span dimensions”, “chordal dimensions” &/or “MOB”.

Program “B&S TO SPAN & CR”

Will convert chordal dimensions for an individual gear (or pinion) to span dimensions & comparator readings.

Program “SPAN TO CR & BS”

Will convert span dimensions for an individual gear (or pinion) to comparator readings & chordal dimensions.

Programs “MOB TO CR BS SPAN O” & “MOB TO CR SPAN E”

Will convert measurement over balls (MOB) for an individual gear (or pinion) to comparator readings, chordal dimensions & span dimensions.
